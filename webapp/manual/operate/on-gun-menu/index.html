The On-Gun Menu

Everything you can set without a phone — and what the gun remembers.

📖official👥communityLast verified 2026-08-27View as Markdown

The gun's LED tells you which mode is selected: white Free For All · red Death Match · yellow Generals · blue Supremacy · pink Commander · green Survival · orange The Swarm. During play the same LED indicates ammo and health.

Source: docs/reference/brx-extended-user-guide.md, docs/reference/brx-manual-notes.md

Navigating the root menu

  1. Power on → you are at the root menu. LEFT / RIGHT cycle game modes; the LED colour changes with each. Trigger selects. 📖official
  2. D-pad picks your team or faction. Trigger cycles weapons (or characters in Supremacy). ALT cycles perks — only in modes that have them. 📖official
  3. Press SELECT to step through the game variables: lives, game time, respawn, volume. D-pad changes each value; SELECT advances. 📖official
  4. Pull the reload handle to start. Settings you changed become the new defaults for that mode. 📖official

Source: docs/reference/brx-manual-notes.md, docs/reference/brx-extended-user-guide.md

Game variables on the gun

Setting Values Notes
Game time Off · 5 · 10 · 15 · 20 · 30 min 📖official
Respawn Off · 15 · 30 · 60 s · Ramp 45 · Ramp 90 "Ramp" grows the penalty with each death, up to the cap 📖official👥community
Volume 1 – 5 📖official

Source: docs/reference/brx-manual-notes.md, docs/reference/brx-extended-user-guide.md

These variables are remembered per game mode and live on the gun. They are not the same numbers the Callsign app uses — the app keeps its own clock and respawn timer on the phone and never writes these to the gun.

Source: docs/reference/brx-extended-user-guide.md, protocol/brx-protocol.md §7n

Button holds worth memorising

  • ALT, hold 3 s — toggle indoor / outdoor (persists). 📖official
  • LEFT at power-on — target mode for sighting. 📖official
  • RIGHT at power-on — "install accessory" pairing mode (headset, grenade, sidearm…). 📖official👥community
  • SELECT at power-on — USB disk mode; no startup sound. 📖official
  • LEFT + RIGHT, hold 5 s in a game — soft reset back to the menu. 📖official
  • LEFT + RIGHT, hold 3 s at the root menu — admin lock (blocks mode changes and reset); add SELECT for the stronger lock that also freezes indoor/outdoor, weapon, team and perk. A locked gun cannot host. 👥community
  • Swing your elbow (gesture-enabled "logo" guns) — melee from the headset's front emitter; other guns use RIGHT. 📖official

Source: docs/reference/brx-manual-notes.md, docs/reference/brx-extended-user-guide.md, docs/reference/community-notes.md
