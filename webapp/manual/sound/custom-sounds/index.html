Custom sounds over USB

Yes, you can put your own audio on a BRX — no firmware hacking, fully reversible

benchofficialcommunityLast verified 2026-08-27How we knowMarkdown

The AUDIO folder. Hold SELECT while powering on with a USB cable attached and the tagger becomes a disk drive: a firmware file at the root and an AUDIO folder of per-sound files. Replace a file, replace a sound. This is Battle Company's own update path, confirmed in their Extended User Guide, and the community has used it for Star Wars packs for years.

Source: docs/reference/brx-extended-user-guide.md, docs/reference/community-notes.md

Back up the whole AUDIO folder before you change anything.

The originals are Battle Company's; the factory restore is their USB updater package (see Firmware updates). Copying files is slow — budget up to an hour per 250 MB — so don't unplug early.

Source: docs/reference/brx-extended-user-guide.md, docs/reference/community-notes.md

Swap a sound

  1. Power the tagger off. Connect the micro-USB Programming Port (not the charging port) to a computer. official
  2. Hold SELECT and switch the gun on. It makes no startup sound — that's the tell that you're in disk mode. A normal power-on never exposes the drive. officialcommunity
  3. A removable disk appears (Windows or macOS) with a .BIN at the root and an AUDIO folder. On older non-logo guns, tap SELECT a few times after entering if nothing shows. official
  4. Copy the entire AUDIO folder to your computer as a backup. community
  5. Prepare your replacement as <ID>.LTP — the file name is the sound id from the bank (e.g. R02.LTP replaces the M4 fire sound, NA0.LTP the death beep). community
  6. Drag it into AUDIO, choose overwrite = yes, and wait for the copy to finish. official
  7. Eject the disk, power-cycle, and test with the on-gun menu (or $PLAY,<id>,4,6,,,,,* over Bluetooth). bench

Source: docs/reference/brx-extended-user-guide.md, docs/reference/community-notes.md, protocol/callsign-extract/sound-bank.md

File facts

Naming:

<ID>.LTP, one file per bank id. Known community swaps: NA0.ltp death loud-beep, VA3.ltp scream, VA5.ltp yell (copy/rename one over another to change the death cue).

Which files are which weapon:

the Callsign-app gun sounds use different file names from the default (on-gun menu) weapon files — replacing one set won't change the other. Default guns to target for the menu game: SR-100, TAC-87, SMG-x3, MG7.

Firmware v4.30+ needs a complete new audio-file set

in AUDIO — after that update, old packs don't line up.

Source: docs/reference/community-notes.md · docs/reference/community-notes.md · docs/reference/community-notes.md

What people build with this

  • Full overlay packs — a complete Star Wars sound set exists in the owner community (credit David Knox); it replaces weapon, hit and voice files wholesale. community
  • Re-skinning the "reflex" sounds — the "phone connected" line, the disabled chirp, low-battery. You can't stop them, but you can make them yours (Open BRX plans an "Open BRX connected" line this way). bench
  • Grenade audio — the explosion, flashbang, gas and CTF music you hear from a grenade are gun-bank files (X/H/JA families); swap those and every grenade "sounds different" with zero grenade modification. benchcommunity

Source: docs/reference/community-notes.md, docs/sound-architecture.md, docs/FOLLOWUPS.md B11, docs/reference/grenade.md

Policy note.

Swapping files in AUDIO changes stored content, not firmware — it's the same mechanism Battle Company's updater uses, and it's reversible. Open BRX's own hard rule is "never modify stock firmware"; sound swaps sit comfortably inside it.

Source: CLAUDE.md, docs/reference/community-notes.md
