# Developer reference
the complete interoperability spec for the BRX tagger + headset: transport, framing, every known command and event with its field map, the `$WEAP` / `$GSET` / `$PSET` / `$SIR` tables, the optical IR word, the USB console, and a copy-paste path from `pip install` to a live game. Every row says how sure we are of the fact it carries.

- [Transport, framing & safety](https://open-brx.iamrossi.workers.dev/manual/dev/transport/): How you reach the gun, what a frame looks like, and why nothing here can brick one. Start here if you want your own code to talk to a tagger.
- [Command reference](https://open-brx.iamrossi.workers.dev/manual/dev/commands/): Every command we know of, with args, meaning and confidence: host → tagger, tagger → host, and headset. This page lists every frame you can send the gun. Copy them exactly as written.
- [The arm sequence: from `$CLEAR` to a live gun](https://open-brx.iamrossi.workers.dev/manual/dev/arm-sequence/): 
- [`$WEAP`: the weapon definition](https://open-brx.iamrossi.workers.dev/manual/dev/weap/): Forty-odd comma-separated tokens that make a weapon out of data: damage, cadence, fire mode, ammo, sounds, IR type. This page maps every token, so you can build a weapon of your own.
- [`$GSET` and `$PSET`: game and player settings](https://open-brx.iamrossi.workers.dev/manual/dev/gset-pset/): The two frames that set on-gun rules and the player's pools, identity and voice pack. Read this page to give each player their health, armor and id.
- [`$SIR`: the incoming-IR effects matrix](https://open-brx.iamrossi.workers.dev/manual/dev/sir/): What an IR hit does to this gun is decided by the victim's table, not by the shooter's weapon. This page shows how to write that table.
- [Events: what the gun tells you](https://open-brx.iamrossi.workers.dev/manual/dev/events/): Hits, health, HUD echoes, buttons and telemetry, plus the proof that the gun keeps no game state. Read this page to learn what the gun sends back to your code.
- [The IR word: what a shot carries through the air](https://open-brx.iamrossi.workers.dev/manual/dev/ir/): A 25-bit pulse-width-encoded word on a 38 kHz carrier, decoded from LaserTagMods' base-station source and verified on our own receiver and emitter. Read this page if you are building your own IR sender or receiver.
- [The USB serial console: `QUERY` and `SETUP`](https://open-brx.iamrossi.workers.dev/manual/dev/serial-console/): The micro-USB "Programing Port" is a Teensy serial console with two commands, not the `$` protocol and not SSH. Plug a tagger into a computer and this page tells you what you can ask it.
- [Headset, link and what survives](https://open-brx.iamrossi.workers.dev/manual/dev/headset-link/): Which state lives where, and what a BLE drop, a headset switch-off, or a power-cycle each wipe. Read this page before you write code that reconnects to a gun.
- [Getting started with `brx-mcp`](https://open-brx.iamrossi.workers.dev/manual/dev/brx-mcp/): From `pip install` to a live game in six commands, plus the MCP tools for driving a gun from an AI agent. Start here to get a working setup fast.
- [Captures: recording and decoding the official app](https://open-brx.iamrossi.workers.dev/manual/dev/captures/): How every fact on these pages was obtained, and how to take the next one. Read this page if you want to record the app yourself.
